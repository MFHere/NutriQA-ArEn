# Diet Nutrition QA - Bilingual (Arabic/English) Dataset
A bilingual (Arabic/English) Diet &amp; Nutrition QA dataset designed to advance Arabic NLP.Provides a high-quality foundation for nutrition-focused language modeling. Suitable for building real-time nutrition assistants, training domain-specific LLMs, and supporting academic research. 

M. F. (2025). DietNutritionQA-ArEnDataset: A Bilingual (Arabic/English) Diet & Nutrition QA Dataset. 
Available at: https://github.com/MFHere/DietNutritionQA-ArEnDataset
